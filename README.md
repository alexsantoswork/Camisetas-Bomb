Camisetas Bomb - E-commerce de Camisetas 👕🔥

Este repositório contém o código-fonte do projeto Camisetas Bomb, uma plataforma de e-commerce dedicada a comercialização de vestuario.


📌 Sobre o Projeto

O objetivo deste sistema é oferecer uma experiência de compra fluida e segura, focada em camisetas de streetwear. O projeto inclui desde a vitrine de produtos até a gestão de logística e atendimento ao cliente.


Destaque de Produto

O sistema foi otimizado para a exibição e venda de modelos da marca Bomb, que produz os produtos garantindo que detalhes de tecido e tabelas de medidas sejam apresentados de forma clara ao usuário.


🚀 Funcionalidades Principais

Catálogo Dinâmico: Categorização por Masculino, Feminino e Promoções.

Cálculo de Frete: Integração simplificada com serviços de entrega e rastreamento em tempo real.

Tabela de Medidas: Guia para auxiliar na escolha do tamanho ideal.

Checkout Seguro: Processamento de pagamentos e conformidade com a LGPD.


🛠️ Tecnologias para o desenvolvimento.

Frontend: [HTML5, CSS3, JavaScript]

Integrações: Checkout de pagamentos PagBank

IA: Gemini
